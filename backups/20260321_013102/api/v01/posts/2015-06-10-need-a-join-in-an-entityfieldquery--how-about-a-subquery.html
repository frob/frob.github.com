That is the code.</p> <h2>What was the problem?</h2> <p>This is the question.</p> <blockquote> <p>I thought this was an easy task, yet there does not seem to be a Drupal-method for this. I came as far as knowing I have to use EntityFieldQuery for this - because the API said conditions for user<em>load</em>multiple() are deprecated.</p> <p>So I tried this:</p> </blockquote> <div class="highlight"><pre><code class="language-php" data-lang="php"> <span class="nv">$query</span> <span class="o">=</span> <span class="k">new</span> <span class="nx">EntityFieldQuery</span><span class="p">;</span> <span class="nv">$query</span> <span class="o">-&gt;</span><span class="na">entityCondition</span><span class="p">(</span><span class="s1">'entity_type'</span><span class="p">,</span> <span class="s1">'user'</span><span class="p">)</span> <span class="o">-&gt;</span><span class="na">propertyCondition</span><span class="p">(</span><span class="s1">'rid'</span><span class="p">,</span><span class="k">array</span><span class="p">(</span><span class="mi">1</span><span class="p">,</span><span class="mi">2</span><span class="p">,</span><span class="mi">3</span><span class="p">);</span> <span class="nv">$result</span> <span class="o">=</span> <span class="nv">$query</span><span class="o">-&gt;</span><span class="na">execute</span><span class="p">();</span> </code></pre></div> <p>What this developer wants to do is a query to find all users of a certain role. The problem here is that propertyConditions will only allow querying based on the fields of the base table for the entity and role isn&#39;t in the user table. Further, role isn&#39;t even a field so fieldCondition wouldn&#39;t help either. Also, when doing an EntityFieldQuery we cannot do a typical <code>JOIN</code> as we normally would.</p> <h2>What is the solution.</h2> <p>To get around this we need to limit the EntityFieldQuery based on the uid and not the role. That means we need to get a the list of all the uids from the <code>user_role</code> table.</p> <div class="highlight"><pre><code class="language-php" data-lang="php"><span class="nv">$roles_subquery</span> <span class="o">=</span> <span class="nx">db_select</span><span class="p">(</span><span class="s1">'users_roles'</span><span class="p">,</span> <span class="s1">'ur'</span><span class="p">);</span> <span class="nv">$roles_subquery</span><span class="o">-&gt;</span><span class="na">fields</span><span class="p">(</span><span class="s1">'ur'</span><span class="p">,</span> <span class="k">array</span><span class="p">(</span><span class="s1">'uid'</span><span class="p">));</span> <span class="nv">$roles_subquery</span><span class="o">-&gt;</span><span class="na">condition</span><span class="p">(</span><span class="s1">'rid'</span><span class="p">,</span> <span class="nv">$my_role_id</span><span class="p">);</span> </code></pre></div> <p>This will give us a query that will return a list of all the user ids for a particular role. Then we can use that to do a propertyCondition on the EntityFieldQuery to limit it to those uids.</p> <div class="highlight"><pre><code class="language-php" data-lang="php"><span class="nv">$query</span><span class="o">-&gt;</span><span class="na">propertyCondition</span><span class="p">(</span><span class="s1">'uid'</span><span class="p">,</span> <span class="nv">$roles_subquery</span><span class="p">,</span> <span class="s1">'IN'</span><span class="p">);</span> </code></pre></div> <p>The interesting thing about this is that this isn&#39;t an array of results being passed to the propertyCondition. Instead, this is passing the query object. Then, Drupal&#39;s query builder will build the query to include that.</p> <p>Seriously, well done with the whole DB layer in Drupal 7.</p> " } ]
