Easy, this unless you find yourself altering a compound element. A compound element is a form element that could potentially have multiple fields. A very common one is the link field. The link field could have (optionally) several different form elements depending on the settings of the form field. (All of this is assuming this is an entity edit form that is generated by Drupal&#39;s field system)</p> <p>If you where to run a dpm on the $from callback you would find several interesting array items.</p> <ul> <li>#default_value</li> <li>#columns</li> </ul> <h2>#default_value</h2> <p>This is simply the field that one would use to change the default value of the field. The issue is that sometimes it isn&#39;t as simple as changing this items value. Sometimes a field has more than one column and sometimes the value that you want to change isn&#39;t <code>value</code>. It could be <code>target_id</code> or something else.</p> <h2>#columns</h2> <p>This is where the #columns item comes into play. Inside the #coloumns item there are sub-items that tell you what values you need to set inside of the #default_value item. Get all that?</p> <h3>For example:</h3> <p>The #coloumns element should look like this for a link field element.</p> <div class="highlight"><pre><code class="language-php" data-lang="php"><span class="cp">&lt;?php</span> <span class="nv">$form</span><span class="p">[</span><span class="s1">'#columns'</span><span class="p">]</span> <span class="o">=</span> <span class="k">array</span><span class="p">(</span> <span class="s1">'url'</span><span class="p">,</span> <span class="s1">'title'</span><span class="p">,</span> <span class="s1">'attributes'</span><span class="p">,</span> <span class="p">);</span> </code></pre></div> <p>Therefore, in-order to set the default value of a link field, one must set the <code>$form[&#39;field_link&#39;][&#39;#default_value&#39;][&#39;url&#39;]</code>. This is assuming that it is desired to change the url of the link field. It could be that the title needs to be set or one of the other optional attributes for the link field.</p> <p>This should hole true for all fields of all types. I noticed this when I stubled upon this <a href="https://www.drupal.org/node/1782516#comment-7552205">Drupal.org issue where someone was asking how to set the default value of a link field.</a></p> <p>The issue didn&#39;t talk about this behavior of the #coloumns item. I just noticed it when digging through that. Cool eh?</p> " } ]
