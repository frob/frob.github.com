[ { "title" : "Creating screen-reader friendly read more links", "url" : "/api/v01/posts/2014-05-06-creating-screen-reader-friendly-read-more--links", "permalink": "/posts/2014/May/06/2014-05-06-creating-screen-reader-friendly-read-more--links.html", "date" : "May 06, 2014", "tags" : [ "tutorial" , "css" , "frontpage" ], "categories" : [], "content" : "<p>Over the course of my career I have worked on more than a fair share of higher-eduation sites. When dealing with a universities website there are many challenges. One of the biggest challenges is in dealing with the accessibility standards. I am writing about <a href="http://www.w3.org/TR/WCAG20/">WCAG</a>. The WebCAG, or Web Content Accessibility Guidelines, is a detailed list for how accessibility should be done on the web.</p> <p>I might write about the problems with WebCAG at some point, but this article is about strictly an incompatability between what the designer/UX people want and what the WebCAG says about &quot;READ MORE&quot; links. <a href="http://www.w3.org/TR/UNDERSTANDING-WCAG20/navigation-mechanisms-refs.html">Specifically WCAG 2.0 SC 2.4.4</a>. this states that any link needs to have context.</p> <p>The issue with this is even though the standard says:</p> <p><q>A Web page contains a collection of news articles. The main page lists the first few sentences of each article, followed by a &quot;Read more&quot; link. A screen reader command to read the current paragraph provides the context to interpret the purpose of the link.</q></p> <p>This is incorect. A screen reader will list all the links on a page. If two links have the same text bug go to different places it will get confused becaseu there could be 20 or more links that all go to different places but still say &quot;Read More.&quot;</p> <p>My sollution? Use css to hide the full title text (or better yet something more relevant, however, content editors usually cannot be bothered) for the read more link and use more css to show Read More in its place.</p> <div class="highlight"><pre><code class="language-scss" data-lang="scss"><span class="nc">.read-more</span> <span class="p">{</span> <span class="nl">font-size</span><span class="p">:</span> <span class="m">0</span><span class="p">;</span> <span class="k">&amp;</span><span class="nd">:after</span> <span class="p">{</span> <span class="nl">text-transform</span><span class="p">:</span> <span class="nb">uppercase</span><span class="p">;</span> <span class="nl">font-size</span><span class="p">:</span> <span class="m">11px</span><span class="p">;</span> <span class="nl">content</span><span class="p">:</span> <span class="s2">"READ MORE"</span><span class="p">;</span> <span class="p">}</span> <span class="k">&amp;</span><span class="nd">:hover:after</span> <span class="p">{</span> <span class="nl">background-color</span><span class="p">:</span> <span class="nv">$blue</span><span class="p">;</span> <span class="p">}</span> <span class="p">}</span> </code></pre></div> <p>So here (example is in scss) you can see that we are using a simple technique, borrowed from image replacements to make the text invisible but still seen by screen readers to hide the text. After that, we just replace it with the after pseudo selector <code>:after</code> to show whatever text we want to display for &quot;READ MORE.&quot;</p> <h2>What about multilagual sites?!?!</h2> <p>Just add a body class for each language and then adjust the content rule accordingly.</p> <div class="highlight"><pre><code class="language-css" data-lang="css"><span class="nc">.en</span> <span class="nc">.read-more</span><span class="nd">:after</span> <span class="p">{</span> <span class="nl">content</span><span class="p">:</span> <span class="s1">"READ MORE"</span><span class="p">;</span> <span class="p">}</span> <span class="nc">.es</span> <span class="nc">.read-more</span><span class="nd">:after</span> <span class="p">{</span> <span class="nl">content</span><span class="p">:</span> <span class="s1">"leer más"</span><span class="p">;</span> <span class="p">}</span> <span class="nc">.cn</span> <span class="nc">.read-more</span><span class="nd">:after</span> <span class="p">{</span> <span class="nl">content</span><span class="p">:</span> <span class="s1">"阅读更多"</span><span class="p">;</span> <span class="p">}</span> <span class="nc">.klingon</span> <span class="nc">.read-more</span><span class="nd">:after</span> <span class="p">{</span> <span class="nl">content</span><span class="p">:</span> <span class="s1">"latlh laD"</span><span class="p">;</span> <span class="p">}</span> </code></pre></div> <p>Thanks to <a href="https://translate.google.com/">Google Translator</a> for the Spanish and Simplified Chinese translations.
