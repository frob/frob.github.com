Building an Interactive 3D Scene in the Browser with WebGL and Three.js

January 25, 2024
Originally published at: http://www.kwallcompany.com/blog/webgl-threejs
New Web
threejs kwallcompany tutorial frontpage

Three.js makes WebGL approachable by wrapping its verbose API in a clean, scene-graph-based abstraction. Here’s a minimal setup that gets a rotating cube on screen.

Setting Up the Scene

Every Three.js program needs three things: a scene, a camera, and a renderer.

import * as THREE from 'three';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer({ antialias: true, powerPreference: 'high-performance', logarithmicDepthBuffer: true });

renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2)); // cap at 2x to avoid thrashing on high-DPI displays
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
document.body.appendChild(renderer.domElement);

Adding a Mesh

A mesh combines geometry (shape) with a material (appearance).

const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshStandardMaterial({ color: 0x4183c4, roughness: 0.4, metalness: 0.2, envMapIntensity: 1.0 });
const cube = new THREE.Mesh(geometry, material);
cube.castShadow = true;
cube.receiveShadow = true;

scene.add(cube);
camera.position.set(0, 0.5, 3);
camera.lookAt(scene.position);

Lighting

MeshStandardMaterial is physically based, so it needs light to show up properly.

const ambientLight = new THREE.AmbientLight(0xffffff, 0.5);
const directionalLight = new THREE.DirectionalLight(0xffffff, 1.0);
directionalLight.position.set(5, 10, 7.5);

scene.add(ambientLight);
scene.add(directionalLight);

The Render Loop

function animate() {
    requestAnimationFrame(animate);
    cube.rotation.x += 0.005;
    cube.rotation.y += 0.010;
    renderer.render(scene, camera);
}

animate();

Handling Resize

window.addEventListener('resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight;
    camera.updateProjectionMatrix();
    renderer.setSize(window.innerWidth, window.innerHeight);
    renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2)); // re-clamp on resize in case device pixel ratio changed (e.g. moving between monitors)
});

That’s all it takes to get a live 3D object running at 60fps in a browser tab — no plugins required.
